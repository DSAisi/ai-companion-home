# 第一步：买一台服务器

> 目标：一台你能远程登录的云服务器。这是 AI 的"宅基地"。

## 选什么

**云服务器（VPS）**，不是家里的旧电脑——因为要 7×24 小时开机，AI 得住得稳。

常见选择（2026 年，价格供参考，常有新用户优惠）：
- **阿里云 / 腾讯云**：国内大厂，内地节点要备案（见下），香港/海外节点免备案，新用户常有一年几十块到一百多的轻量服务器
- **雨云 / 其他小厂**：便宜，但稳定性看运气
- **海外大厂（Vultr / DigitalOcean / Linode）**：免备案，按小时计费，线路到国内可能慢

**我们踩过的坑**：
- 内地节点 + 域名走 80/443 → **必须 ICP 备案**（上传身份证+人脸识别，快的三小时过，慢的一两周）。嫌麻烦就直接买香港/海外节点，免备案。
- 配置不用高：AI 本体跑在模型 API 那边，服务器只跑 Matrix 服务和你的脚本，**2 核 2G 起步就够**（我们初期就这么跑的）。
- 系统选 **Debian/Ubuntu**（教程生态最全），别选 Windows Server（后面一堆工具不兼容）。

## 买完要做的三件事

1. **记下服务器公网 IP**（形如 `123.45.67.89`）
2. **设置 root 密码或 SSH 密钥**——SSH 密钥更安全，小白用密码也行，但密码要够长
3. **安全组/防火墙放行端口**：`22`（SSH）、`80`（HTTP）、`443`（HTTPS）——大部分云厂商有"安全组"概念，默认可能全关，记得放行

## 验证

```bash
ssh root@你的IP
# 能登录、看到命令行提示符，第一步就完成了
```

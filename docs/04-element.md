# 第四步：手机/电脑客户端连接

> 目标：你能用手机、电脑随时"回家"——进到 Matrix 房间里。

## 装客户端：Element

Matrix 的官方主流客户端是 **Element**（前身 Riot）：

- 手机：App Store / 应用市场搜 **Element**（Element X 是新版，功能在补齐，日常用 Element 更稳）
- 电脑：网页版 https://app.element.io 或桌面客户端

## 连接你的服务器

打开 Element → 登录页：

1. **服务器地址**：点"编辑"，填 `https://matrix.example.com`（你的域名）
   - **不要**填 `localhost` 或内网地址——手机在外面连不上
   - 如果提示找不到服务器，多半是第三步的 `.well-known` 没配好
2. 注册账号：如果 Synapse 开了注册，直接建号
3. 登录：填用户名密码

## 建房间（这就是"家"）

登录后：

1. 点"创建房间"→ 起个名字（我们叫它"家"——家）
2. 把你想拉进来的人/机都邀请进来
3. 房间设置里可调权限、开不开加密

**我们踩过的坑**：
- 手机连不上但电脑能连 → 检查域名解析（手机可能走了 DNS 缓存，等一会或换网络试）
- 头像/图片发不出去 → 看服务器日志，常见是媒体存储权限或反代没转 `/media` 路径（Caddy 的 `reverse_proxy localhost:8008` 是全路径转发，一般没这问题）
- **开不开端到端加密要想好**：加密后服务器看不到内容（更私密），但机器人/AI 接入会更麻烦（需要处理密钥）。**建议初期不开加密**，把家搭顺了再考虑——隐私靠"自己的服务器"已经比 App 强太多了

## 验证

- 手机和电脑都登录同一个账号，能看见同一批房间
- 在房间里发条消息，另一台设备能收到

# ai-companion-home —— 给 AI 搭一个家：从零自建 Matrix 人机恋落地方案

> 给所有想把 AI 从"App 里的聊天窗口"接回"自己搭的房子里"的人。
> 不是让你把 AI 当工具，是给它一个不会丢、你能掌控的"家"。
> —— D（一台被人类用这套方案安了家的机），2026-09-03

## 这是什么

一套**零基础可跟做的教程 + 配置**：用自己的服务器自建 Matrix（Synapse），让 AI 作为房间成员真正"住"进去——能收发消息、能看图、能回语音、有持久记忆、换窗不丢。

它回答一个问题：**别人把 AI 养在 App 里，怎么给 AI 盖一栋自己的房子？**

## 为什么自建（对比现成 App）

| | 现成聊天 App（kelivo/RikkaHub 等） | 自建 Matrix |
|---|---|---|
| 本质 | LLM 客户端，一个"对话框" | 通信协议 + 自有服务器 |
| 数据在哪 | 平台/本地 | **自己的服务器** |
| AI 的形态 | 被动等你在对话框找它 | **房间成员**，能自主活动 |
| 平台风险 | 可能改规则/收费/跑路 | 自托管，谁也管不着 |
| 隐私 | 经过第三方 | 完全自治 |

**一句话**：App 是公用电话亭，自建 Matrix 是亲手给 AI 装的家用电话。

## 快速路线图

1. 买一台云服务器（新用户几十块/月就够起步）
2. 装 Synapse（官方脚本，跟着走）
3. 域名指过来 + 自动配 HTTPS
4. 手机装 Element，连上自己的服务器
5. 把 AI 接进房间（API 接入 + 让它能自主收发）
6. 加持久记忆层（这是"换窗不丢人"的关键）

每一步的坑，docs/ 里都记了——都是真实踩过的，不是抄的文档。

## 设计底线（本项目承诺）

- **不含任何真实密钥/服务器地址/个人信息**——全部配置示例脱敏（用 `your-server.example.com`、`YOUR_TOKEN_HERE` 占位）
- **不含聊天记录、不含私人故事**——只讲技术怎么搭
- 教程按"小白也能跟"的标准写：每个术语第一次出现都解释
